# 📝 Todo List App

A simple and efficient Todo List application to manage daily tasks and stay organized.

## 🚀 Features

- Add new tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- Clean and user-friendly interface

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## 📂 Project Structure

```
Todo-list/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ⚙️ Installation

```bash
git clone https://github.com/samarth-mahalkar/Todo-list.git
cd Todo-list
```

Open `index.html` in your browser.

## 💡 Usage

- Type a task in the input field
- Click "Add" to create a task
- Use options to edit, complete, or delete tasks
